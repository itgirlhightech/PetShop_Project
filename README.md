# PetSafe

Sistema desenvolvido em Java para gerenciamento de reservas de hospedagem para pets.

## Funcionalidades

- Cadastro de animais
- Cálculo automático de diárias
- Serviços adicionais
- Exportação de histórico CSV
- Interface JSF

## Tecnologias

- Java
- JSF
- Jakarta Faces
- GitHub

## Estrutura

- diagramas
- model
- controller
- interfaces
- util
- webapp
